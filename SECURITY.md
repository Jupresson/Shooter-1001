# Security Policy

## Reporting a serious vulnerability
Please only use this process for **serious security vulnerabilities**, such as:
- Remote code execution
- Authentication or authorization bypass
- Exposure of sensitive data or credentials
- Other issues that put users at real risk

Please **do not** open a public issue for these. Report them privately via [GitHub's private vulnerability reporting](../../security/advisories/new) or by contacting **Jupresson.Business@gmail.com**.

Include:
- A description of the problem and its impact
- Steps to reproduce
- The affected version or commit

We aim to respond within **7 days**.

## Minor issues
For low-severity problems, general bugs, or hardening suggestions, please open a regular public issue instead.
